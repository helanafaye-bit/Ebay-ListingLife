About
A simple interface for your active listings of an E-commerce site, split into categories. Each item shows an end date so you know when to remove it from your eBay/shop and refresh with new stock. You can also use it to track which categories/ items sell most often. Bulk Import of stock & sold items of CSV files available for convenience


Ensure Python is installed.
Launch Install requirments when first downloaded.

Open 'ListingLIFE.bat' to open the app & storage server

You will need to generate a short lived dropbox token every time, add it in the HTML app settings and save.
